# SOC 2 Evidence Tracker

## Objective

Track evidence required to support the testing and assessment of SOC 2 controls.

## Evidence Tracking Approach

Each evidence item is linked to a control and records:

- Evidence ID
- Control ID
- Evidence Description
- Evidence Owner
- Period
- Status
- Review Notes
