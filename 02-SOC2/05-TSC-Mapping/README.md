# SOC 2 Trust Services Criteria Mapping

## Objective

Map relevant controls to the applicable Trust Services Criteria (TSC) based on the risks and objectives addressed by each control.

## TSC Mapping

### Security

Security focuses on protecting the system and information against unauthorized access, unauthorized disclosure, unauthorized modification, or destruction.

Relevant controls:
- C-001 — MFA for Privileged Accounts
- C-002 — Role-Based Access Control
- C-003 — Least Privilege

### Confidentiality

Confidentiality focuses on protecting information designated as confidential from unauthorized access or disclosure.

Relevant controls:
- C-002 — Role-Based Access Control
- C-003 — Least Privilege

### Availability

Availability focuses on ensuring the system is available and usable for operation as committed.

Relevant controls:
- C-004 — Daily Backup
- C-005 — Restore Testing

## Mapping Summary

| Control ID | Control | TSC |
|---|---|---|

| C-003 | Least Privilege | Security / Confidentiality |
