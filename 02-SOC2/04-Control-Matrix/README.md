# SOC 2 Control Matrix

## Objective

Map identified information security risks to relevant controls, control objectives, Trust Services Criteria (TSC), and control owners.

## Purpose

The Control Matrix provides a structured view of how identified risks are addressed through implemented controls.

## Control Mapping Approach

Risk → Control → Control Objective → TSC → Owner

## Key Controls

### C-001 — MFA for Privileged Accounts
- Risk: R-001
- TSC: Security
- Objective: Ensure privileged access is protected from unauthorized use.
- Owner: IT/Security

### C-002 — Role-Based Access Control
- Risk: R-001
- TSC: Security / Confidentiality
- Objective: Ensure system access is assigned according to approved roles.
- Owner: IT/Security

### C-003 — Least Privilege
- Risk: R-002
- TSC: Security / Confidentiality
- Objective: Ensure users receive only the access required for their responsibilities.
- Owner: IT/Security

### C-004 — Daily Backup
- Risk: R-003
- TSC: Availability
- Objective: Ensure critical data can be recovered after a disruption.
- Owner: IT/Security

### C-005 — Restore Testing
- Risk: R-003
- TSC: Availability
- Objective: Validate that backups can be successfully restored.
- Owner: IT/Security
