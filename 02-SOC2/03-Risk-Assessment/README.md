# SOC 2 Risk Assessment

## Objective

Identify and assess key information security risks affecting the Maju Jaya HR Cloud Platform.

## Risk Assessment Approach

Risks are evaluated based on:

- Asset
- Threat
- Vulnerability
- Risk
- Likelihood
- Impact
- Risk Level
- Proposed Treatment

## Key Risks

### R-001 — Unauthorized Access to Employee Personal Information

- Asset: Employee Personal Information
- Threat: Attacker
- Vulnerability: Weak authentication / lack of MFA
- Risk: Unauthorized access or disclosure of employee personal information

### R-002 — Unauthorized Payroll Data Access or Modification

- Asset: Payroll Data
- Threat: Insider / Unauthorized User
- Vulnerability: Excessive privileges / weak access control
- Risk: Payroll data may be accessed or modified without authorization

### R-003 — HR Service Unavailability or Data Recovery Failure

- Asset: HR Cloud Application / Production Database
- Threat: Cloud outage / disaster
- Vulnerability: Inadequate recovery capability
- Risk: HR services may become unavailable or data may not be recoverable after a disruption

## Disclaimer

This is a fictional SOC 2 simulation created for learning and portfolio purposes. It does not represent a real SOC 2 examination or professional audit engagement.
