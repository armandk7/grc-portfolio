# System Description

## Overview

Maju Jaya provides a cloud-based HR application hosted on AWS infrastructure.

The platform processes employee personal information, payroll-related data, attendance data, and HR reports.

The system is managed by the Engineering and IT/Security teams.

## System Components

### Infrastructure
- AWS cloud infrastructure
- Production database
- Network infrastructure

### Software
- HR Cloud Application
- APIs
- Supporting application services

### People
- Engineering Team
- IT/Security Team
- Customer Support Team

### Processes
- Access Management
- Change Management
- Incident Management
- Backup and Recovery

### Data
- Employee personal information
- Payroll-related information
- Attendance data
- HR reports

## Security and Operational Processes

Key security and operational processes supporting the system include access management, change management, incident management, and backup and recovery.
