# SOC 2 Scope

## Objective

Define the systems, people, infrastructure, data, and processes included in the simulated SOC 2 examination.

## In Scope

The SOC 2 examination covers:

- HR Cloud Application
- Production Database
- AWS infrastructure supporting the HR application
- Engineering team responsible for the application
- IT/Security team responsible for infrastructure and security
- Relevant security and operational processes

## Out of Scope

The following are excluded from the simulated examination:

- Internal Finance System
- Marketing Website
- Corporate HR System used only for Maju Jaya employees

## Trust Services Criteria

The simulated assessment primarily focuses on:

- Security
- Confidentiality
- Availability

## Disclaimer

This is a fictional SOC 2 simulation created for learning and portfolio purposes. It does not represent a real SOC 2 examination or professional audit engagement.
