# GRC & Cybersecurity Compliance Portfolio

## About This Portfolio

This repository contains simulated Governance, Risk, and Compliance (GRC) projects designed to demonstrate practical knowledge of information security, risk management, compliance, audit support, and security assurance.

The portfolio focuses on practical application of:

- ISO/IEC 27001
- SOC 2
- NIST Cybersecurity Framework (CSF)
- NIST SP 800-53
- NIST Secure Software Development Framework (SSDF)
- Third-Party Risk Management (TPRM)
- Vendor Security Assessment
- Security Assurance

## Projects

- ISMS scope definition

- Internal audit
- Audit findings
- CAPA

- Gap assessment
